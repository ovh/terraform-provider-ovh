# ovh_vpss (Data Source)

Use this data source to list the VPS of your account.

Each element of `vps` has the attributes of the [`ovh_vps`](https://registry.terraform.io/providers/ovh/ovh/latest/docs/data-sources/vps) data source.

-> **NOTE** The schema of this data source changed in version 3.0.0 of the provider. See the [VPS migration guide](../guides/vps_migration) to update a configuration written for a previous version.

## Example Usage

```terraform
data "ovh_vpss" "all" {}

output "vps_ids" {
  value = data.ovh_vpss.all.vps[*].id
}
```

Select the VPS of a region:

```terraform
data "ovh_vpss" "all" {}

output "vps_in_gravelines" {
  value = [for vps in data.ovh_vpss.all.vps : vps.id if vps.location.region == "eu-west-gra"]
}
```

## Notes

The VPS are listed in the order the API returns them. Use `sort(data.ovh_vpss.all.vps[*].id)` for a sorted list of identifiers.

A VPS whose service is expired is left out of the list, with a warning that names it.
