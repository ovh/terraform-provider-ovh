# ovh_okms_log_subscription

Forwards the logs of an OVHcloud KMS to a Logs Data Platform stream.

A KMS has one log kind per API: `audit-kmip` for the KMIP audit logs, `audit-servicekey` for the REST API audit logs of the service keys and `audit-secret` for the REST API audit logs of the secrets. `GET /v2/okms/resource/{okmsId}/log/kind` lists them with their fields. Each subscription forwards one kind, so forwarding several kinds takes one resource per kind.

## Example Usage

```terraform
resource "ovh_dbaas_logs_output_graylog_stream" "kms" {
  service_name = "ldp-xx-xxxxx"
  title        = "KMS secret audit logs"
  description  = "OVHcloud KMS REST API audit logs of the secrets"
}

resource "ovh_okms_log_subscription" "secret" {
  okms_id   = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  kind      = "audit-secret"
  stream_id = ovh_dbaas_logs_output_graylog_stream.kms.stream_id
}
```

~> **Note:** The subscription is created and deleted asynchronously through a Logs Data Platform operation, so the APIv6 token used by the provider must have `GET` access on `/dbaas/logs/*/operation/*` in its token ACL. When the provider authenticates as an IAM user or a service account, its policies must allow `okms:apiovh:log/subscription/create`, `/get` and `/delete` on the KMS, and `ldp:apiovh:output/graylog/stream/forwardTo` on the Logs Data Platform service holding the stream.

## Schema

### Required

- `kind` (String) Log kind name to subscribe to. The kinds available are listed by `GET /v2/okms/resource/{okmsId}/log/kind`
- `okms_id` (String) ID of the KMS
- `stream_id` (String) Identifier of the Logs Data Platform stream the logs are forwarded to

### Read-Only

- `created_at` (String) Creation date of the subscription
- `id` (String) Identifier of the subscription
- `ldp_service_name` (String) Name of the Logs Data Platform service holding the stream
- `resource_name` (String) Name of the subscribed resource, where the logs come from
- `resource_type` (String) Type of the subscribed resource, where the logs come from
- `updated_at` (String) Last update date of the subscription

## Import

A subscription can be imported using the `okms_id` and its `id`, which `GET /v2/okms/resource/{okmsId}/log/subscription` lists, separated by `/`:

```bash
$ terraform import ovh_okms_log_subscription.secret okms_id/subscription_id
```
