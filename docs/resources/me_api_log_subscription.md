# ovh_me_api_log_subscription

Forwards the activity logs of the OVHcloud account to a Logs Data Platform stream.

The account activity logs record the actions done on the account, through API calls and in the Control Panel. See [Generating OVHcloud account logs with Logs Data Platform](https://docs.ovhcloud.com/en/guides/manage-and-operate/iam/logs-forwarding) for the content of the logs.

## Example Usage

```terraform
resource "ovh_dbaas_logs_output_graylog_stream" "activity" {
  service_name = "ldp-xx-xxxxx"
  title        = "account activity logs"
  description  = "OVHcloud account activity logs"
}

resource "ovh_me_api_log_subscription" "activity" {
  kind      = "default"
  stream_id = ovh_dbaas_logs_output_graylog_stream.activity.stream_id
}
```

~> **Note:** The subscription is created and deleted asynchronously through a Logs Data Platform operation, so the APIv6 token used by the provider must have `GET` access on `/dbaas/logs/*/operation/*` in its token ACL. When the provider authenticates as an IAM user or a service account, its policies must allow `account:apiovh:me/api/log/subscription/create`, `/get` and `/delete`, and `ldp:apiovh:output/graylog/stream/forwardTo` on the Logs Data Platform service holding the stream.

## Schema

### Required

- `kind` (String) Log kind name to subscribe to, such as `default`. The kinds available are listed by `GET /me/api/log/kind`
- `stream_id` (String) Identifier of the Logs Data Platform stream the logs are forwarded to

### Read-Only

- `created_at` (String) Creation date of the subscription
- `id` (String) Identifier of the subscription
- `ldp_service_name` (String) Name of the Logs Data Platform service holding the stream
- `resource_name` (String) Name of the subscribed resource, where the logs come from
- `resource_type` (String) Type of the subscribed resource, where the logs come from
- `updated_at` (String) Last update date of the subscription

## Import

A subscription can be imported using its `id`, which `GET /me/api/log/subscription` lists:

```bash
$ terraform import ovh_me_api_log_subscription.activity subscription_id
```
